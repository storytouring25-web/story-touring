# Story Touring

เว็บไซต์คลังโปรแกรมทัวร์เอเชีย (จีน ญี่ปุ่น เกาหลี เวียดนาม ลาว เมียนมา) พร้อมระบบค้นหา กรองตามประเทศ และฟอร์มขอใบเสนอราคา — ทำเป็นหน้าเดียว (single page) แบบ responsive รองรับทั้งเดสก์ท็อปและมือถือ

## โครงสร้างไฟล์

- `index.html` — หน้าเว็บทั้งหมด (HTML + CSS + JavaScript รวมในไฟล์เดียว ไม่ต้องพึ่งไลบรารีภายนอกนอกจากฟอนต์ Google Fonts)
- `assets/logo-story-touring.png` — โลโก้บริษัท

## การเปิดดู

เปิดไฟล์ `index.html` ด้วยเบราว์เซอร์ได้เลย ไม่ต้องมีเซิร์ฟเวอร์

## ฟีเจอร์

- เมนูนำทางแบบ dropdown (เดสก์ท็อป) และแฮมเบอร์เกอร์ (มือถือ) สลับที่จุดตัด 1040px
- ค้นหาโปรแกรมด้วยคำค้นและกรองตามประเทศแบบเรียลไทม์
- การ์ดโปรแกรมทัวร์ 12 รายการ
- ฟอร์มขอใบเสนอราคาแบบ modal พร้อมสถานะยืนยันการส่ง
